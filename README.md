# Loomly

A full-stack e-commerce web application built with React and Node.js.

## Features

- User registration and authentication
- JWT authentication with refresh token rotation
- Product browsing and product details
- Search and product filtering
- Shopping cart management
- Protected routes
- User profile
- Checkout flow
- Responsive design
- RESTful API

## Tech Stack

### Frontend

- React
- React Router
- Bootstrap
- Axios
- Vite

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- REST API
